# Mini App AutoClicker v5 — HONOR X8b

Версия ориентирована на портретный экран HONOR X8b и Telegram Mini App.

## Проверка
1. Установить APK.
2. Включить службу в «Специальные возможности».
3. Включить автокликер.
4. Открыть игру в Telegram.
5. Нажать «Играть?».
6. В приложении можно проверить «Тестовый прыжок».

Тестовый жест длится 200 мс. Координаты рассчитываются относительно текущего разрешения экрана, поэтому код не привязан к одному числу пикселей.
